Bisontes DUX · Admin

Entrar

El panel guarda los cambios directamente en GitHub (urpito/BisontesDUX) y la web se actualiza sola en 1-2 minutos. Para entrar necesitas un token de GitHub con permiso para editar el repositorio.

Cómo crear el token (una sola vez)
  1. Entra en github.com/settings/personal-access-tokens/new.
  2. Nombre: «Admin web Bisontes». Caducidad: la que quieras.
  3. Repository access → Only select repositories → BisontesDUX.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Pulsa Generate token, cópialo y pégalo aquí.

El orden de la lista es el orden en la web. El «apodo» es lo que sale estampado en la espalda de la camiseta (si no hay, sale el apellido).

Cuerpo: separa los párrafos con una línea en blanco. Una línea que empiece por ## es un subtítulo.
